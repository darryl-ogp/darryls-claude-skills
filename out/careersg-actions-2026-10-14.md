## Why this didn't land

The Notion MCP connector reconnected partway through this session and gained
`notion-delete-pages`, `notion-update-comment`, `notion-set-discussion-resolved`
and a few others — but still exposes **no tool that edits page content**. It has:

`notion-create-comment`, `notion-create-database`, `notion-create-pages`,
`notion-create-view`, `notion-delete-comment`, `notion-delete-databases`,
`notion-delete-pages`, `notion-fetch`, `notion-get-comments`,
`notion-get-enabled-skills`, `notion-get-teams`, `notion-get-users`,
`notion-query-data-sources`, `notion-query-meeting-notes`, `notion-search`,
`notion-set-comment-reaction`, `notion-set-discussion-resolved`,
`notion-update-comment`, `notion-update-enabled-skills`

What I tried, per CLAUDE.md, on both 9 Oct and again today:

1. `ToolSearch` `select:mcp__Notion__notion-update-page` → `No matching deferred tools found`
2. `ToolSearch` keyword queries (`notion update page content`,
   `+notion update existing page blocks content edit`,
   `tool access availability upgrade notion connection`) → only read/create tools
3. Direct call to `mcp__Notion__notion-update-page` →
   `Error: No such tool available: mcp__Notion__notion-update-page`
4. Direct call to `mcp__Notion__notion-get-tool-access` (the confirmation step
   CLAUDE.md asks for) →
   `Error: No such tool available: mcp__Notion__notion-get-tool-access`
5. `ToolSearch` for `notion-update-blocks`, `notion-append-block`,
   `notion-update-data-source`, `notion-move-pages`, `notion-duplicate-page` →
   `No matching deferred tools found`

Per CLAUDE.md I did not substitute: no comment on the CareerSG page, no
replacement page, no Slack post. This is a draft for you to apply, not a
delivered run.

The likely fix is reconnecting Notion with write scope, or running this skill
from a session that has the full Notion connector attached.
