## Why this didn't land

The Notion MCP connector available to this session is read/create only. It
exposes:

`notion-ai-search`, `notion-create-comment`, `notion-create-database`,
`notion-create-pages`, `notion-create-view`, `notion-fetch`,
`notion-get-comments`, `notion-get-teams`, `notion-get-users`,
`notion-query-data-sources`, `notion-query-meeting-notes`, `notion-search`

There is no update/edit tool. What I tried, per CLAUDE.md:

1. `ToolSearch` with `select:mcp__Notion__notion-update-page` →
   `No matching deferred tools found`
2. `ToolSearch` keyword queries (`notion update page content`,
   `+notion update existing page blocks content edit`,
   `tool access availability upgrade notion connection`) → returned only the
   read/create tools listed above
3. Direct call to `mcp__Notion__notion-update-page` →
   `Error: No such tool available: mcp__Notion__notion-update-page`
4. Direct call to `mcp__Notion__notion-get-tool-access` (the confirmation step
   CLAUDE.md asks for) →
   `Error: No such tool available: mcp__Notion__notion-get-tool-access`
5. `ToolSearch` for `notion-update-blocks`, `notion-append-block`,
   `notion-update-data-source`, `notion-move-pages`, `notion-duplicate-page` →
   `No matching deferred tools found`

Per CLAUDE.md I did not substitute: no Notion comment on the CareerSG page, no
replacement page, no Slack post. The checklist above is a draft for you to apply,
not a delivered run.

The likely fix is reconnecting the Notion connector with write scope, or running
this skill from a session where the full Notion connector is attached.
